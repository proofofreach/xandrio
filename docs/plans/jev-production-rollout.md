# Jev verifier and source-preservation rollout

User authorized implementation and production deployment on 2026-09-21. Scope: optional Jev verifier cascade through Vercel, correct PPQ GLM response alias and usable verification output budget; deterministic preservation of preformatted line breaks and explicit Kindle chapter markers. No automatic semantic chapter merging, no new role-filtering policy, no PDF feature enablement.

Before implementation, failure cases: provider429/timeout/malformed/missing/extra answers or wrong route must fall back for the entire batch; uncertain judgments go to configured verifier; cancellation must not trigger fallback; no secret/evidence logs; concurrent jobs must not flood Jev; failed judgments must never mark claims supported. New verifier policy must invalidate certification/checkpoint identity; prior GLM certification must not certify Jev. Existing certification gates stay intact. No enabling allowUncertified to bypass a gate. Deployment may expose the pilot only where existing policy explicitly allows uncertified guides; otherwise leave cascade disabled until certification.

Text cases: preformatted line breaks preserved without changing ordinary HTML source wrapping, removing scripts/styles or interpreting encoded tags; MOBI heading detection must not split contents, quotations or nonconsecutive/duplicate chapter markers. Preserve all source words/order and source references; keep reliable authored TOC boundaries. Do not migrate existing saved positions blindly; source artifacts retain old chapters while new imports use changed extraction. Check cache-version consequences before bumping.

Verification strategy: write isolated failure-case and actual-source end-to-end checks before product changes, retain repeatable JSON artifacts; run existing guide/provider/import tests, full repository release tests, browser smoke and import benchmark. Live Jev check uses public controls only. Inspect existing exact-revision VPS release path and GitHub billing constraints before publication. Independent plan/code review before release.
